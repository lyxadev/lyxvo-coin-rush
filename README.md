# Lyxvo Coin Rush

A small Godot 4.2 game. Collect coins for points, avoid the red enemy, beat the 60-second timer, and try for a high score.

- Move: arrow keys or WASD
- Start / restart: ENTER or SPACE

Open `project.godot` in Godot 4.2+ and press Play.

## Web build

Every push to `main` exports the game to HTML5 with GitHub Actions and publishes it to GitHub Pages (Settings → Pages → Source: GitHub Actions).
